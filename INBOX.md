# Входящие обращения
Все сообщения ниже — учебные данные.

## A1 Пересечение бронирований
На версии demo-1 администратор подтвердил аудиторию 204 на 10:00–11:00 и на 10:30–11:30 одного дня. Обе записи сохранились со статусом confirmed. Ожидалось отклонение второго подтверждения. Подготовленное свидетельство: samples/conflict-evidence.json.

## A2 Та же аудитория занята дважды
Пользователь прислал тот же сценарий аудитории 204 на 10:00–11:00 и 10:30–11:30 в demo-1. Это повтор A1, нового условия нет.

## A3 Выгрузка моих бронирований
Пользователь просит CSV только со своими записями за выбранную дату. Нужно согласовать поля, порядок строк, заголовок и поведение при пустом результате. Для первой итерации реализацию не обещали.

## A4 Тёмная тема
Пользователь хочет переключатель оформления. Критериев пока нет. На ближайшую итерацию ресурсов не выделено, запрос сохраняется для будущего обсуждения.

## A5 Всё работает медленно
В сообщении нет версии, действия, числа записей и измеренного времени. Нельзя уверенно локализовать проблему. Нужно запросить недостающие сведения, а не назначать исправление наугад.

## A6 Нет описания формата данных
В README нет расшифровки полей samples/bookings.json. Новый участник не понимает формат времени и допустимые статусы. Это можно исправить документом docs/data-format.md без изменения программы.
